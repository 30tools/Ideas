# Ideas Directory

This directory contains all project ideas for 30tools.com. Each idea is documented in its own markdown file following the structure defined in `TEMPLATE.md`.

## Organization

- Each idea should be in a separate `.md` file
- Use descriptive, kebab-case filenames (e.g., `markdown-table-generator.md`)
- Follow the template structure for consistency

## Adding Ideas

See the [CONTRIBUTING.md](../CONTRIBUTING.md) guide for detailed instructions on adding new ideas.

## Tracking

All ideas are tracked in the main [README.md](../README.md) table for easy overview.
