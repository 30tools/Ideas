# Contributing to Ideas Repository

Thank you for your interest in contributing ideas for 30tools.com!

## How to Contribute

### Adding a New Idea

1. **Fork the repository** (if you're not a direct collaborator)

2. **Create a new idea document**:
   - Copy `TEMPLATE.md`
   - Create a new file in the `ideas/` directory
   - Use kebab-case for the filename (e.g., `url-shortener-tool.md`)

3. **Fill out the template**:
   - Provide clear, concise information
   - Be as specific as possible about the problem and solution
   - Include realistic estimates

4. **Update the README**:
   - Add your idea to the Current Ideas table in `README.md`
   - Include the name, brief description, priority, status, and link

5. **Submit a Pull Request**:
   - Write a clear PR description
   - Reference any related issues

### Improving Existing Ideas

- Comment on the idea file with suggestions
- Open an issue for discussion
- Submit a PR with improvements

### Idea Review Process

1. Ideas are reviewed for clarity and feasibility
2. Community feedback is gathered
3. Priority is assigned based on impact and effort
4. Ideas move through statuses: Idea → Planning → In Progress → Complete

## Best Practices

- **Be Specific**: Vague ideas are hard to evaluate
- **Focus on Problems**: Start with the problem, not the solution
- **Consider Users**: Who will benefit from this tool?
- **Think Small**: Small, focused tools are easier to build and maintain
- **Research First**: Check if similar tools already exist

## Questions?

Open an issue with the "question" label for any questions about the contribution process.
